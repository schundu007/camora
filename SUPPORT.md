# Getting help

## Using Camora

- **Product docs** live in the app at [camora.cariara.com/docs](https://camora.cariara.com/docs)
  — getting started, audio setup, the live interview modes, the playground, and billing.
- **Something is broken?** Open a [bug report](https://github.com/schundu007/camora/issues/new?template=bug_report.yml).
- **Account, subscription or refund question?** Those are not GitHub issues — use the
  support link in the app.

## Working on Camora

- **Setting it up locally** — [Run it locally](README.md#run-it-locally).
- **Conventions, and the provider-separation rule that catches everyone** —
  [CONTRIBUTING.md](CONTRIBUTING.md).
- **Architecture and repo layout** — the README, then `CLAUDE.md` at the repo root, which
  is the long-form version and is kept current.
- **Stuck on something specific?** Open an issue with what you tried. A question that
  exposes a gap in the docs is a useful contribution in itself.

## Security

Never in a public issue — see [SECURITY.md](SECURITY.md).

## Response times

This is maintained alongside a full-time job. Issues and PRs usually get a first response
within a few days; security reports are prioritised over everything else.
