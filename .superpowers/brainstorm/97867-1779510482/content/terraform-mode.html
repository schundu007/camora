What does "Terraform" mean in the playground?

Same question as Docker — what level of execution do you need?

A

Validate only — terraform validate

You type HCL (.tf content) in the left pane. Hit Run → runs terraform init -backend=false + terraform validate. Catches syntax errors and invalid references. No provider credentials needed.

Pro

  • Fast (<3s), no cloud creds
  • Safe to run on server

Con

  • Won't catch provider-level errors
B

Plan with null provider

Write HCL using the null or random provider (no real cloud). Hit Run → terraform plan output shows the full resource graph. Lets you practice plan reading.

Pro

  • Real plan output
  • No cloud credentials needed

Con

  • Slower (provider download on first run)
  • Scoped to null/random providers only
C

Lint only — tflint

Static analysis with tflint: catches deprecated syntax, missing required vars, best-practice violations. Similar to hadolint for Dockerfile — no Terraform binary needed.

Pro

  • Instant, zero infra cost
  • Good style feedback

Con

  • Doesn't validate logic, only style/syntax
