Advanced Learning Features — Beginner → Pro

Grouped by tier. No AI — all tool-backed. Select the tiers you want.

1

Tier 1 · Real-time Feedback Foundation

  • Ruff linting as-you-type — debounced 500ms, inline squiggles + gutter icons before you even hit Run. Catches undefined vars, bad imports, style issues instantly.
  • Error decoder — when a run fails, the stderr panel auto-parses Python tracebacks and appends a plain-English "What went wrong" block. Lookup table of 50+ common errors (NameError, IndexError, RecursionError…). No AI, just rules.
  • Keyboard shortcuts — ⌘+Enter to run, ⌘+L to clear, ⌘+D to format. Shown in a persistent footer chip.
  • Auto-format (Black) — a "Format" button pipes code through black - on the backend and replaces the editor content. Teaches idiomatic Python style.
2

Tier 2 · Program Insight Intermediate

  • Variable Inspector — after every run, backend wraps code to capture locals() at script end, returns as JSON. Right pane shows a table: name · type · value. Teaches what's in memory.
  • Execution Profiler — toggle button "Profile". Wraps code in cProfile, returns top-10 functions by cumtime as a sortable table. Teaches where time is spent.
  • Memory Tracker — second toggle "Memory". Wraps code in tracemalloc, shows peak memory + top 5 allocations by file/line. Teaches memory awareness.
  • Run History — last 20 runs saved in localStorage per language tab. Drawer on the right shows timestamp + first line of code + exit code. Click any to restore. Teaches iteration habits.
3

Tier 3 · Test-Driven Mindset Advanced

  • Test Harness panel — second collapsible editor below main code (labelled "Tests"). Backend runs both files as pytest -v --tb=short. Output shows pass ✓ / fail ✗ per test function with assertion diff. Teaches TDD.
  • Complexity Badge — after each run, backend uses radon to compute McCabe complexity + LOC. Shows a badge: A (simple) → F (spaghetti). Click for per-function breakdown. Teaches clean code.
  • Snippets Library — slide-out panel with 60+ categorised snippets: List Comprehensions, Decorators, Generators, Context Managers, Dataclasses, Async/Await, Type Hints, Functools, Itertools. Click to insert at cursor. Teaches patterns by example.
4

Tier 4 · Pro Tooling Expert

  • Big-O Visualiser — "Benchmark" button. Backend runs your function 5× with input sizes [10, 100, 1k, 10k, 100k], records time for each. Right pane plots a sparkline + classifies curve as O(1) / O(log n) / O(n) / O(n²). Teaches algorithmic thinking.
  • Share snippet — "Share" button persists code to DB, returns a short URL (/playground/s/abc123). URL loads the code pre-filled. Teaches collaboration.
  • REPL mode — toggle between "Script" (full file) and "REPL" (line-by-line). In REPL mode, Enter sends one expression to a persistent Python process, output appends below. State accumulates across lines. Teaches exploratory coding.
  • Diff view — "Compare runs" — select any two entries from Run History and view a side-by-side code diff + output diff. Teaches how changes affect behaviour.

Select all tiers you want — or pick just some. Recommended: all 4 for a complete learning arc.
