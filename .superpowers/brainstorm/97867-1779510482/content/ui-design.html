Design notes

  • Each tab keeps its own editor content in component state (no cross-tab bleed)
  • Monaco syntax mode: python · shell · dockerfile · hcl
  • Output pane: stdout in green, stderr in red, exit code + duration in muted footer
  • Run button shows spinner while executing; disabled during in-flight request
  • Output scrolls independently from editor
