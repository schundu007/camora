class DevImageBuilder:
def find_build_schedule(self, developers, deadlines, layers):
for dev in developers: ①
deps = layers[dev].dependencies ②
schedule[dev] = deadline[dev]
if dep not in schedule: ③
schedule[dep] = min(schedule.get(dep, inf), deadline[dev] - 1) ④
CHANGES
① Missing colon
Added : at end of for statement — Python syntax requires it.
② Typo fixed
dependancies → dependencies
③ Added: guard
Skip deps already scheduled to avoid overwriting tighter deadlines.
④ Added: propagation
Backwards deadline propagation: dep must finish before dev's deadline.
